# Security Policy

## Scope

OpenCode Security Guard is security-sensitive software intended to reduce accidental and intentional exposure of local secrets to LLM agents.

Please report suspected vulnerabilities privately rather than opening a public issue.

## Reporting

For the public repository, use GitHub Security Advisories where available. If that mechanism is unavailable, contact the repository maintainers privately.

Please include:

- affected version or commit;
- OpenCode version;
- operating system;
- configuration involved;
- reproduction steps;
- expected and observed behavior;
- whether any credential or sensitive data may have been exposed.

Do not include live credentials in reports.

## Important

If a credential may have been exposed to an LLM provider, treat it as compromised and rotate/revoke it immediately. A security control cannot retract data that has already been transmitted.
