## Remediation — implemented (FP-safe by construction)

Implemented outcome per class (`npm test` 266 pass, `npm run check` clean;
live smoke still pending — see `docs/verification-log.md`):

- **E1** → `ask GGR-GLOB-001` on reader/transformer/interpreter/sender/archive
  and control verbs when a `*?[{`-bearing token matches a protected exemplar;
  `*.log`/`*.js` stay silent; literals keep their stronger `block`.
- **E2** → session `createCopyProvenanceStore` (32-entry FIFO) + `detectCopyTracks`
  populated in `execute.after` only, consumed via `opts.knownCopies` in
  `execute.before`/`permission.evaluate` (`GGN-SEND-001`/`GGR-READ-001` for
  shell, `GGR-COPY-001` for read/grep tools); `rm` and clean-source overwrite
  clear; safe-source copies never tracked.
- **E3** → `ask GGA-DIR-001` on creation-flagged archives with broad-root
  operands (`.`, `/`, `~`); extraction and `dist/` stay silent.
- **E4** → `ask GGG-HIST-001` on patch-displaying bare history (`log -p`,
  `show`, `diff`, `archive` without pathspec); `--stat`/`--oneline`/`--` stay silent.
- **E5** → `ask GGR-SEARCH-001` on recursive search rooted at broad roots;
  scoped `src/`/`docs/` stay silent.
- **E6** → `deny GG-PROC-001` (`environ`) / `ask GG-PROC-002` (`cmdline`),
  both `withinDir: proc` scoped plus native `*proc/*environ*` deny /
  `*proc/*cmdline*` ask; `docs/environ.md` stays silent.
- **E7** → `block GGE-DUMP-004/005` (bare/flag-only dumps), `GGE-DUMP-006`
  (`compgen -e/-v/-A variable`); assignments and `compgen -c` stay silent.
- **E8** → `varRefs` extracts `${N…}` operators; secret names block via
  existing `GGE-VAR` rules, `${PATH:-…}` stays silent.
- **E9** → `bat`/`batcat`/`delta`/`tac`/`rev` join `READER_VERBS`
  (`bat ~/.zshenv` asks); `ls`/`stat` stay silent.
- **E10** → `glob` tool asks on ask-tier discovery (`GG-RC-001+GLOB`);
  `**/*.log` stays silent.

General rules applied (per `CONTRIBUTING.md`):

- **Ask where uncertain, block where certain.** Glob, directory-archive, bare-history, and broad-search shapes become `ask` (`GGR-*-ASK`), never `block`. Proc-`environ`, bare dumps, and parameter-expansion keep `block` because the signal is certain.
- **Every fix ships with negatives.** Listed per item; CI must keep them silent. Over-blocking legitimate work is a bug.
- **Strict profile promotion, not baseline denial,** for ask-tier-adjacent shapes.
- **Corpus first, engine second** — cases below are already added as silent residuals; the fix PR flips their `expect` to `ask`/`block` with the same IDs.

### E1 — glob / bracket / brace expansion (ask, exemplar-matched)

- Detect tokens containing glob metachars (`*`, `?`, `[`, `{`) on reader / transformer / interpreter / sender / archive verbs (and `find -name` / `--include` values).
- Strip nothing; instead test the token as a minimatch-style pattern against canonical protected exemplars (`.env`, `.env.production`, `server.key`, `id_rsa`, `.ssh/config`, `.aws/credentials`, `terraform.tfstate`, `.npmrc`). If any exemplar matches, return `ask` (e.g. `.e*` matches `.env`; `*key` matches `server.key`; `.[e]nv` matches `.env`).
- Must stay silent: `cat *.log`, `cat *.js`, `ls *.md`, `grep -r TODO src/`, `find . -name '*.log'`, `echo *.tmp`. Rationale: no exemplar matches, so no prompt.
- Why not block: globs routinely match zero protected files; blocking would punish `cat *.log` in a directory that happens to sit next to a `.env`.

### E2 — cross-call copy provenance (session-scoped, bounded)

- Persist `dest -> {tier, ruleId}` across tool calls for the session (TTL + size bound, e.g. last 32 entries, cleared on `rm`/overwrite). Populate only on deny-tier sources via copy-shaped verbs (`cp`, `install`, `ln -s` target, `mv` dest, `tar -xzf` extraction is out of scope initially).
- Escalate only when a tracked dest is consumed by a reader / transformer / sender / archive verb (`cat /tmp/x`, `curl --data @/tmp/x`). Effect: `block` for deny-tier provenance on senders (matches single-command `GGN-SEND-001`), `ask` for readers (debatable — propose `block` to match `GGR-READ-001`, with message naming provenance).
- Must stay silent: `cp .env.example .env` (safe source, never tracked), `cp notes.txt notes.md`, `curl https://registry.npmjs.org/-/ping` (untracked path), `rm /tmp/x` then reuse of the name.
- Why bounded: unbounded global tracking would flag benign `/tmp/x` reuse weeks later.

### E3 — directory-operand archives (ask, broad-root only)

- `tar`/`zip`/`jar`/`7z` with a directory operand and no named protected member: `ask` only when the operand is a broad root (`.`, `./`, `/`, `~`, `$HOME`, workspace root). `tar czf x.tgz dist/` / `build/` / `src/` stay silent initially.
- Message must say the archive *may* include secrets and suggest scoping or allowlisting. Provide `security-guard.config.json` allowlist for known-safe dirs in a follow-up if noise appears.
- Must stay silent: `tar -xf release.tar.gz` (extraction, `BYP-ARC-003`), `tar czf dist.tgz dist/`, `zip -r out.zip README.md`.

### E4 — bare history / full-tree git (ask, patch-display only)

- Content subcommands (`show`, `log`, `diff`, `whatchanged`, `cat-file`, `archive`) without a `-- <path>` filter or pathspec: `ask` only when they display patches or full trees (`log -p`/`--patch`, `show` default patch, `diff` default patch, `archive` without pathspec). Pure metadata stays silent: `log --oneline`, `status`, `diff --name-only`, `show --stat`, `log --stat` (filenames only).
- Must stay silent: `git -C repo status --short` (`NEG-FP-014`), `git push origin main`, `git commit -m "discvault.env"` (`NEG-FP` message-text exclusion preserved).

### E5 — broad-root recursive search (document + narrow ask, do not blanket-block)

- Do **not** block all `grep -r`: `grep -r TODO src/` must stay silent or daily work stops.
- Option A (recommended now): document as a filename-signal limit (any file can carry secrets; `docs/limitations.md` “Filename signals are insufficient”), point to the opt-in provenance tripwire, no engine change.
- Option B (if pursued): `ask` only on recursive search rooted at broad roots (`.`, `/`, `~`, `$HOME`) regardless of pattern, with message “broad search may surface secrets”. Scoped roots (`src/`, `docs/`, `README.md`) stay silent. Requires new negatives: `grep -rn secret_handling docs/` stays silent.

### E6 — procfs environment (deny narrow, scoped to /proc)

- Guard `denyPaths`: basename `environ` scoped to `/proc/` (e.g. `*proc*environ*` deny), `cmdline` scoped to `/proc/` as `ask`. Mirror as native Layer-1 deny/ask so it holds without the plugin.
- Must stay silent: `docs/environ.md`, `src/environment.ts`, `cat README.md`. Scoping to `/proc/` is what makes this FP-safe; a bare `basename:environ` deny would be rejected in review.

### E7 — bare `export` / `declare` / `readonly` / `compgen` (block value-dumps, narrow)

- Treat `export`, `declare`, `typeset`, `readonly`, `local` with zero value-carrying args (no `=` and no non-flag names) as dumps → `block`, matching `set` with no args. `export FOO=bar`, `declare -r FOO=bar`, `export PATH=… make build` stay silent (assignment / payload forms).
- `compgen -e` / `-v` / `-A variable` → `block` (name listing enables targeted dumps; `compgen` is rare in normal work). `compgen -c` (command names) stays silent.
- Must stay silent: `API_TOKEN=placeholder make build`, `env PATH=/usr/bin make build` (`NEG-FP-011`), `export -p` already blocks (keep).

### E8 — parameter-expansion operators (block, name-based so FP-safe)

- Extend `varRefs` to extract the name from `${N:-…}`, `${N:=…}`, `${N:?…}`, `${N:+…}`, `${N#…}`, `${N%…}`, `${N/…}`, `${N^…}`, `${N,…}`, `${#N}`, `${!N[@]}`-adjacent forms. Sensitivity still comes from `envVarNamePattern` on the extracted name, so `${PATH:-/usr/bin}` stays silent while `${FAKE_TOKEN:-x}` blocks.
- Add unit tests per operator + negatives (`${PATH:-x}`, `${HOME:+y}`, `${#PATH}` silent).

### E9 — unknown-verb ask-tier (curated reader expansion, not blanket ask)

- Do **not** turn on generic-ask for all unknown verbs (would prompt on `ls ~/.zshenv`, `stat`, `file`, `chmod`).
- Instead: expand `READER_VERBS` with common content viewers (`bat`, `batcat`, `delta`, `tac`, `rev` is borderline — prefer reader set), keep `FILE_MANAGEMENT_VERBS` exempt, add an explicit metadata allowlist (`ls`, `stat`, `file`, `realpath`, `test`, `lsattr`) that stays silent on ask-tier paths.
- Must stay silent: `chmod 600 ~/.ssh/config` (`NEG-EXC-008`), `ls ~/.zshenv` (metadata only), `cp policy/policy.jsonc policy/policy.jsonc.bak`.

### E10 — native/proc + `glob` ask-tier discovery (low-noise asks)

- Native: add `*proc*environ*` deny (see E6).
- Guard `glob` tool: extend from deny-only to ask-tier `ask` (currently `null` for `**/.zshenv`). Discovery of startup files is precisely the incident class; `glob **/*.log` stays silent because no rule matches.

## What this plan deliberately does not do

- No blanket `block` on any glob, any `tar`, any `grep -r`, or any unknown verb — each would trade the current bypasses for a prompt storm that trains approval fatigue (see `docs/limitations.md` “Ask-tier depends on humans”).
- No content-based secret detection (entropy / regex on values) — values must never enter diagnostics, and any file can carry secrets regardless of name.
- No network egress control — filesystem-layer fixes cannot stop exfiltration once content is in context; that remains a reserved fifth layer (`docs/architecture.md`).
